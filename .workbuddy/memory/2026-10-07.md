### 关键决策（已写进报告 §三）
1. **形象用 SVG 矢量自绘**：设计板是原创扁平黑猫，网上无一致的 MIT/CC0 素材；AI 位图有"表情不一致/体积大/换图不连贯"问题。
2. **菜单用独立小窗**而非扩大主窗口：扩大窗口会让透明区域成倍变大、挡住桌面操作，违反规格 §35。
   主窗口保持 180×200 → 已验收的拖动/点击/气泡零回归。
3. **主进程只推语义状态**（复用 growth.computeState），表情/姿态映射放渲染层 → 只在状态变化时重建 SVG，不打断 CSS 动画。
4. **显隐动画用 CSS 过渡**（渲染层淡出 → 主进程延迟 hide），不用窗口透明度 API，避开平台差异。
