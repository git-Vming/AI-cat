# 《桌面电子宠物「阿七」V1.0》

**项目类型：** Windows 本地桌面电子宠物 / 工作陪伴工具 / 轻养成系统
**项目代号：** A-QI V1.0
**核心定位：** 陪伴工作、记录工作、提醒工作、通过真实工作时长养成宠物
**运行方式：** 完全本地化运行
**网络依赖：** 无
**云端依赖：** 无
**数据迁移：** 支持完整文件夹迁移

---

# 一、项目核心理念

阿七不是单纯的桌面动画。

阿七是一只**陪用户一起工作的电子宠物**。

用户每天打开公司的电脑以后，与阿七进行：

> **「上工」**

下班以后进行：

> **「下工」**

阿七根据用户实际工作的时间获得经验值，并随着工作天数和工作时长逐渐成长。

整个系统的核心关系：

```text
用户真实工作
      ↓
    上工
      ↓
   工作计时
      ↓
    下工
      ↓
计算实际工作时长
      ↓
   获得 EXP
      ↓
    阿七成长
      ↓
解锁新的互动/外观/内容
```

因此：

> **用户认真工作，就是在养阿七。**

# 二、V1.0 第一核心功能：上工 / 下工

这是阿七 V1.0 的核心功能，优先级高于其他所有玩法。

## 2.1 上工

用户每天到公司打开电脑后，可以点击阿七：

```text

```

```text
🐱 阿七

早上好！

今天也一起努力吧。

上工时间：
2026-10-02 08:03

当前状态：
🟢 工作中
```

系统开始记录本次工作时间。

# 四、标准工作时间

V1.0 已知用户正常工作时间：

### 上午

**08:00 → 12:00**

工作 4 小时。

### 午休

**12:00 → 14:00**

不计入工作时间。

### 下午

**14:00 → 18:00**

工作 4 小时。

因此正常工作日：

> **每日标准工作时长 = 8小时**

---

# 五、经验值规则

基础规则：

> **实际工作 1 小时 = 10 EXP**

因此：

```text
1小时   = 10 EXP
2小时   = 20 EXP
4小时   = 40 EXP
8小时   = 80 EXP
10小时  = 100 EXP
```

这里必须明确：

> **经验值按照实际工作时长计算，而不是按照“打开电脑到关闭电脑”的自然时间计算。**

例如：

```text
08:00 上工
12:00 午休
14:00 继续工作
18:00 下工
```

实际工作：

```text
4小时 + 4小时 = 8小时
```

获得：

```text
80 EXP
```

而不是 100 EXP。

---

# 六、午休机制

V1.0 不要求用户进行：

> 「午休打卡」

因为用户已经明确：

```text
12:00 下班
14:00 上班
```

系统自动将：

```text
12:00–14:00
```

认定为：

> 午休时间

因此当天可以存在两个工作时段：

```text
08:00–12:00
14:00–18:00
```

最终合并计算当天实际工作时长。

# 七、异常打卡处理

这是 V1.0 必须解决的问题。

## 7.1 忘记上工

例如周一：

用户正常来到公司，但是忘记点击：

> 「上工」

直到下午才想起来。

阿七不能直接制造一条错误记录。

应该允许：

```text
🐱 阿七

你今天好像忘记上工了。

是否补录？

[补录上工时间]
```

用户可以选择：

```text
08:00
08:15
08:30
自定义时间
```

补录以后：

> 工作记录标记为「补录」。

# 八、忘记下工

例如：

```text
08:00 上工
18:00 忘记下工
```

第二天打开电脑：

阿七提醒：

> “昨天是不是忘记跟我说下班啦？”

然后：

```text
检测到：

2026-10-01
上工：08:02
下工：未记录

是否补录下工时间？

[补录]
[暂不处理]
```

这样避免因为忘记下工导致系统把：

> 昨天 08:00 → 今天 08:00

全部算成工作时间。

# 十、工作日加班定义

V1.0 暂定：

> 周一至周五，超出正常工作时间的实际工作时间，计入工作日加班。

例如：

### 情况一

```text
08:00 上工
12:00 午休
14:00 上工
20:00 下工
```

正常：

```text
08:00–12:00 = 4h
14:00–18:00 = 4h
```

加班：

```text
18:00–20:00 = 2h
```

当天：

```text
正常工作：8h
工作日加班：2h
总工作：10h
经验：100 EXP
```

同时：

```text
工作日加班次数 +1
工作日加班时长 +2h
```

---

# 十一、早到也应当能够记录

例如：

```text
07:30 上工
18:00 下工
```

系统应该记录：

```text
07:30–08:00
```

作为：

> 工作日额外工作时间

因此：

```text
正常工作：8h
额外工作：0.5h
总工作：8.5h
EXP：85
```

V1.0 可以统一称为：

> **工作日额外工作时长**

其中可以进一步区分：

```text
正常工作
早到
晚走
```

这样以后统计会更加准确。

---

# 十二、周末加班

周六、周日不是强制工作日。

但是用户可能需要加班。

因此周末：

> **允许自由上工 / 下工。**

例如：

```text
周六

09:00 上工
13:00 下工
```

系统记录：

```text
周末加班次数：+1
周末加班时长：4小时
获得 EXP：40
```

周末没有：

> 08:00–12:00 / 14:00–18:00

这种强制标准。

只要用户主动：

> 「上工」

系统就开始计时。

# 十七、工作记录与养成系统的关系

工作记录不是单独存在的。

它和阿七成长直接关联。

```text
上工
 ↓
产生工作时长
 ↓
下工
 ↓
获得EXP
 ↓
生成/更新工作记录
 ↓
完成待办
 ↓
阿七成长
```

这样不会出现：

> “为了养宠物而做工作。”

而是：

> **工作本身就是养宠物。**

> 本次护眼提醒已触发

不影响 EXP。

# 十九、久坐提醒

如果用户持续处于工作状态：

> 🐱 “你是不是已经和椅子融为一体了？”

建议默认：

> 连续工作 90 分钟提醒一次。

同样：

> **提醒不是任务，不完成也不扣经验。**

阿七的定位是陪伴，而不是监督。

# 二十四、阿七 V1.0 形象

默认采用：

> **2D 像素风小猫**

原则：

1. 优先采用明确开源许可证的素材
2. 优先 MIT / CC0 / 明确允许修改和再分发的素材
3. 可以基于开源素材二次设计
4. 保留必要的许可证和署名文件
5. 不使用来源不明的网络图片
6. 不使用受版权保护的商业角色
7. 不因为“开源代码”就默认美术素材也可以使用

程序架构应该让：

> **宠物程序与宠物皮肤分离。**

未来可以更换阿七的外观，而不需要重写整个程序。

你有新的任务：

> 阿七帮你记住。

你坐太久：

> 阿七提醒你起来走走。

你看屏幕太久：

> 阿七提醒你休息眼睛。

> 第二天阿七提醒你。

> 阿七帮你记录。

一个月以后：

> 阿七知道你这个月工作了多久、加班了多少次。

几个月以后：

> 阿七也随着你的工作一起成长。

而当你离开这家公司：

> **把 A-Qi 文件夹带走。**

你的工作记录、成长数据和阿七本身，一起带走。
