## 二、关键设计决策

### 2.1 ⭐ 核心红线：互动**只加好感度，绝不产生 EXP**

README §二十二写得很明确：

> **工作时长是 EXP 的绝对核心来源。不能让用户靠疯狂点击互动刷经验。**

所以我把这条做成**结构性保证**，而不是靠自觉：

- `interact()` 只写 `affection` / `interactionCount` / `interactionsToday` —— **完全不碰 `totalExp`**；
- `totalExp` 仍由 `attendance.json` 全量派生（阶段 4 的架构），互动链路根本没有修改它的代码路径；
- **每条互动动作都有每日上限**（见 2.3），从源头堵住"狂点刷好感度"；
- 测试直接断言：连续互动后 `pet.totalExp` 与 `statistics.totalExp` **仍为 0**、等级不变。

### 2.2 宠物状态机（规格 §32/§33）

规格要求至少支持 9 种状态，已全部在 `growth.js` 中定义：
`IDLE / WALK / SLEEP / HAPPY / SAD / WORKING / EATING / DRINKING / REMINDING`

**当前可被触发的 7 种**（判定优先级从高到低）：

| 状态 | 触发条件 |
|---|---|
| `REMINDING` | 提醒气泡正在显示 |
| `WORKING` | 正在上工（规格 §33 的"工作陪伴"特色状态；**不影响工作计时**） |
| `HAPPY` | 摸头/玩耍后 12 秒内，或升级后 20 秒内 |
| `EATING` / `DRINKING` | 喂食 / 喂水后 12 秒内 |
| `SLEEP` | 22:00–06:00 且未在工作 |
| `IDLE` | 其余情况（默认） |

> **`WALK` 与 `SAD` 当前不会主动产生**：WALK 需要动画素材（阶段 8），SAD 的触发规则规格未定义。
> 我把它们保留在状态表里，等阶段 8 落地动画时使用 —— **没有自己发明规则**。

### 2.3 互动动作与每日上限（防刷）

| 动作 | 默认每日上限 | 互动后状态 |
|---|---|---|
| 🤚 摸摸头 | 5 次 | HAPPY |
| 🍚 喂点吃的 | 3 次 | EATING |
| 💧 给它喝水 | 3 次 | DRINKING |
| 🧶 陪它玩会儿 | 3 次 | HAPPY |

每次互动 **好感度 +1**（一天最多 +14）。跨天自动归零（`interactionsToday` 只保留当天）。
次数用完时按钮自动禁用并提示"今天的次数用完啦，明天再来陪阿七吧"。

> **这些数值是我定的**（规格只写了"简单好感度"，没有给具体数字），**请你确认或直接给新数值**。

### 2.4 升级解锁（README §二十三）

每升 1 级解锁 1 件，共 8 件：

| 等级 | 解锁 | 等级 | 解锁 |
|---|---|---|---|
| Lv.2 | 🎩 帽子 | Lv.6 | 🪴 植物 |
| Lv.3 | 👕 衣服 | Lv.7 | 🛋 沙发 |
| Lv.4 | 🥤 水杯 | Lv.8 | 🛏 床 |
| Lv.5 | 💻 小电脑 | Lv.9 | 🏆 工作奖杯 |

**两个刻意的设计：**
1. **解锁只增不减**：补录导致等级下降时，**已解锁的道具不回收** —— 养成不该倒退，这对用户更友好；
2. **启动时自动补全**：老数据的 `pet.json` 里 `unlockedItems` 是空的（阶段 7 之前没有这个逻辑），
   而你的等级已经 Lv.3。所以程序启动时会全量重算一次，**自动把该有的道具补上**。
   你这边实测结果：**Lv.3 → 🎩帽子 + 👕衣服**（下一件 `Lv.4 🥤水杯`）。

### 2.5 升级提示

升级时（下工结算或补录导致升级）弹出**气泡**（复用阶段 6 的气泡）：

```
阿七升级了！现在是 Lv.4 🎉
解锁了：🥤水杯
```
气泡仍然遵守阶段 6 的规则：**不自动消失，点击才关**。

### 2.6 窗口形态

沿用你已确认的做法：**一个普通窗口（带系统标题栏）上下两区** —— 上半「❤️ 互动」、下半「🎒 宠物状态」；
托盘「❤️ 互动」「🎒 宠物状态」打开同一窗口，只是滚动定位 + 自动刷新。

**为什么不在卡片上做？** 卡片只有 180×200，已在满负荷；加按钮会裁切。完整卡片菜单属阶段 8。

## 四、数据模型变化

`pet.json` 新增一个字段（其余字段沿用规格 §5 原本就定义的 `affection` / `unlockedItems` / `interactionCount`）：

```jsonc
{
  "name": "阿七", "level": 3, "exp": 3.5, "totalExp": 163.5,
  "affection": 0,                    // 好感度（互动获得）
  "createdAt": "2026-10-03",
  "skin": "default",
  "unlockedItems": ["hat", "clothes"],   // 已解锁道具 id
  "interactionCount": 0,                 // 累计互动次数
  "interactionsToday": {                 // ← 阶段 7 新增：只保留当天计数
    "date": "2026-10-05",
    "counts": { "pat": 0, "feed": 0, "water": 0, "play": 0 }
  }
}
```

**没有新增 JSON 文件**（仍是 5 个：pet / attendance / statistics / settings / tasks）。
